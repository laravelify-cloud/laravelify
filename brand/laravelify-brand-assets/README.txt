Laravelify brand assets
=======================
Every image is in two formats: svg/ (vector, scales to any size) and png/ (the number in the
name is the width in pixels). PNGs have transparent backgrounds unless the design has its own.

01-logo       Full logo: on-dark (main), on-light, white, black; wordmark only (on-dark, on-light).
              Wordmark is Instrument Sans SemiBold, drawn as outlines. "ify" is the accent color.
02-mark       The badge on its own (avatars, GitHub org picture, stickers): color, white, black.
              A white "L" (the Laravel stack) with a yellow chevron (deploy, ship it up).
03-app-icon   Square full-bleed icons (iOS/Android round them): purple, and dark.
04-social     og:image 1200x630 (+2400 @2x), GitHub social preview 1280x640,
              README banners 1600x400 (dark and light).

Colors
  Purple       #6B16ED  brand (buttons, links in light mode)
  Purple light #8B5CF6  gradient start
  Purple deep  #5A12C7  gradient end
  Yellow       #FCD452  accent (dark mode, the chevron, "ify" on dark)
  Ink          #0A0A0A  text on light
  Night        #09090B  dark backgrounds

Font: Instrument Sans (SIL Open Font License), the same as the panel.
Favicons are in ../laravelify-favicons.
